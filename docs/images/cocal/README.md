# Cocal promo screenshots

Captured from the real calendar components in the interactive demo at
https://cocal.io on 2026-09-07. The demo uses fictional accounts and sample events.

- `day-view.png`: expanded day view showing Work and Personal together.
- `event-details.png`: created-event card with attendees, timezone context,
  description, and conflict status.
- `logo.svg`: unchanged copy of Cocal’s canonical transparent logo at
  `packages/web/public/cocal-logo-type.svg` in the Cocal repository. It preserves
  the original artwork, colors, proportions, and lettering.

Captured in light mode at a 1440px browser viewport. The surrounding website and
chat container were excluded from the captures; the calendar components were not
restyled. Refresh both images from the live demo when the product UI changes.
